# qthe — CTO Brief

## One-paragraph value statement

qthe turns a founder's physics-flavored research vision into the fleet's
cleanest demonstration of priced research: an 8-bit substrate primitive (6
bits amplitude, 2 bits "timbre" operator state) with an integer-exact
kernel whose algebra is proven by exhaustion, whose mechanism is
deterministic to the byte, and whose performance claims are pre-registered
experiments where honest nulls are celebrated. Around the kernel sits a
full honesty stack — pre-registered gates, an independent Python
re-derivation that matched 10,272/10,272 vectors, a no-floats fixed-point
plane, a twelve-experiment arithmetic series, and a cache-gamed AI "guest"
whose outputs were sealed and then priced by arithmetic. The asset is
equal parts substrate, method, and proof that the method works.

## What it does & for whom

- **Substrate researchers / embedded-tinkering teams:** a zero-dependency
  cellular substrate with an exact embedding pass (integer `{re, im}`
  outputs), a non-local coupling table, and a browser live-mirror — all in
  ~270 lines of readable ESM plus a strict Python twin.
- **The fleet:** the canonical example of LAYER-0/1/2 honesty splits,
  pre-registration discipline (including the preserved G4 honest-FAIL
  pattern), and cross-implementation conformance doctrine; its receipt
  chains and the two-reader rule are reused as templates by other lanes
  (jev-garden uses qthe as a LAYER-0 substrate).
- **Decision-makers:** a worked answer to "how do you adopt a visionary's
  claims without either believing or dismissing them" — you price them.

## Maturity assessment

**Working research prototype with hardened verification.** Evidence: gate
suite all-pass of record (with one preserved prediction-error FAIL +
post-hoc PASS — the honesty is the feature), Python cross-impl byte-exact
over the full specified surface, fixed-point plane priced to the S-unit,
E-Q12 verdict 10/10 with Brier 0.00167, browser smoke 5/5 checklist, and
the two-reader installment 9/9. It is not productized: no packaging, no
performance engineering, the LAYER 2 headline claims (C1, C4, C5) remain
open by design, and one lever (the cascade half) is re-parked with a
committed receipt.

## Risks

| Risk | Status / mitigation |
|---|---|
| Sibling dependency (quilt-stone) missing → gate suite refuses | Documented, fail-closed; sealed runs of record cover verification without re-runs. |
| Kernel edits invalidate every sha pin | By design; the edit workflow (new lineage + new gate run) is documented in the developer guide. |
| Float-plane vs fixed-plane divergence on engineered rational sigmas | Priced and receipted (P-B1 autopsy); treated as two lineages with a measured translation table. |
| Speculative framing attracting over-claiming | The SPEC itself marks the gifted "proof" decorative (C3 note) and keeps claims open; docs repeat it. |
| JS Number horizon (±2^53 inputs) | Named (F1); Python path raises instead; battery bounded below the seam deliberately. |
| Security | Clean: no secrets, no network in the repo's own lanes; tavern artifacts are sealed data with provenance, and historical API keys were operator-side env vars, never committed. |

## Cost profile

- Compute: laptop-class. Gate suite sub-minute; heaviest sealed runs
  (254,520-triple enumeration; 2M paired-event pricing) are CPU-minutes.
- Services: none for the substrate itself. The tavern's external model
  calls were operator-keyed and receipted per turn (cache economics files);
  the demo is a static page served by any http server.
- Maintenance: near zero; the pins watch the kernel.

## Strategic options

- **Maintain + harvest-learnings (recommended):** the substrate is stable
  and the method (pre-registration, cross-impl conformance, honest FAIL
  preservation, two-reader rule) is already fleet doctrine. Keep qthe as
  the reference.
- **Invest:** only if an application wants an exotic, fully-deterministic
  embedding/CA substrate (art, generative tooling, education). The open
  LAYER 2 claims are the research upside; discharging C1/C2 properly is
  the next real milestone.
- **Retire:** not indicated — the verification stack is green where
  runnable, the honest-negative record is a fleet asset, and downstream
  (jev-garden) builds on it.
