# crossimpl/c — REGISTRATION (ORCH-7, pre-run)

**Law:** the C port must be BYTE-EXACT against the reference kernels on the
fixture battery, or it does not ship as a port. Pricing-first: this
registration, the port (`qthe_core.h` / `qthe_core.c`), the runner
(`conformance.c`), and the generator (`gen_fixtures.mjs` — which executes the
REFERENCE kernels to produce the fixtures, never the C side) are committed
BEFORE the conformance run; the result commit carries the sealed outcome.

## The port contract

- **Scope:** LAYER 0 complete (pack/unpack/tauOf/dOf, split-channel
  vectorPass in exact int64) + LAYER 1 complete (64-slot wormhole table,
  toroidal Moore-8 tick with pre-tick snapshot [R2], live row-major LWW
  reads [R2/R4], tau frozen, nextD rule table, caller-side mulberry32) +
  the canonical plane hash (sha256 over `WxH@t=T:<hex>`, matching
  `experiments/_harness.mjs`).
- **Two planes:** float mode (σ as double, byte-identical to `qthe.mjs`)
  and fixed mode (σ_q as uint64, byte-identical to
  `fixedpoint/qthe_fixed.mjs`, R8).
- **Sigma never comes from libm.** It travels as IEEE754 bit patterns
  (16 hex chars) in the fixtures; the C lazy default for log₂(3) is the
  exact bit constant `0x3FF95C01A39FBD68` taken from the JS reference.
  Division/multiply/add are correctly rounded on every IEEE754 platform, so
  term bits agree; `log2()` is NOT correctly-rounded-guaranteed, so it is
  never called.
- **Zero dependencies** beyond libc. C99, no build system: one `cc` line.

## The battery (fixtures.txt, generated by gen_fixtures.mjs)

- 4 vectorPass cases (4×6, 8×3, 1×1, 5×5, seeded weights + signed xs).
- 12 substrate cases, float plane: E-Q1 twin-delivery ON/OFF (200 ticks),
  P-B3-style random at σ=2/3 and default (the coupled-family territory),
  checkerboard cascade, σ ∈ {0.5, 4} arms, 8×8 all-Abstain cooker (LWW
  cascade), the E-Q8 same-slot boards at σ=2/3 and 8/5 (the float-only
  artifact sites), a fresh twin family, a handcrafted mixed board.
- 3 fixed-plane cases: random at σ_q=2863311531 (2/3) and default
  σ_q=6807362106, plus the E-Q8 board at 2/3 (the fixed side of the
  artifact).
- Every case records: initial plane (hex), full event list
  (tick,x,y,slot,resonance + term BITS for float / term_q integer for
  fixed), and the canonical final plane hash.

## Floors (frozen before the run)

- **C1-ALL:** every case PASS — final plane hash equal, event count equal,
  every event tuple equal, every term bit-pattern (float) or integer
  (fixed) equal. Zero mismatches. Any single mismatch = the port is NOT
  byte-exact: honest FAIL, autopsy against the JS side, no partial credit.
- **C2-RNG:** mulberry32 exactness is covered implicitly by every
  random-seeded case (the initial planes were produced by the JS
  mulberry32; the C side replays the recorded planes, and the C rng is
  additionally exercised by the port's own callers — a dedicated KAT is
  NOT in this battery; the rng's first-party verification is the JS-side
  fixture reproduction itself).
- **C3-NO-LIBM:** the port must compile and pass without `-lm` (no math
  library anywhere).

## Honest-null space

If any case fails, the port dies as a port until repaired and re-registered;
the failure row stays in the chain beside the attempt. If all pass, the C
port joins python as the second independent re-derivation, and the fixed
plane gains its first non-JS implementation.

## Receipt discipline

One stone-v1 chain: `crossimpl/receipts/cimpl_chain.jsonl` (append-only,
verify-from-disk, refuse-if-broken). The chain records: the fixtures sha256,
the compiler and flags, per-family results, and the verdict. The chain is
added to `scripts/verify_all_chains.mjs` and `scripts/probe_gate.mjs`
STONE_CHAINS as part of this registration commit (addition, never
subtraction).
